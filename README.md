# ONT Gala phone check-in

The phone check-in page for the ONT Gala. Volunteers open it on their phones, scan ticket QR codes with the camera, and check guests in.

This page holds no PIN and no link to the guest list. The organizer sends volunteers a link with the check-in server address, plus a PIN sent separately.

The source and setup guide are in the main (private) `ont-gala` repository, under `mobile/`.
